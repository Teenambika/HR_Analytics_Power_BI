# HR Analytics Dashboard

## Project Overview

This project analyzes employee data to understand workforce trends,employee performance,engagement,satisfaction and
employee attrition.

## Tools & Technologies Used

-Power BI - Dashboarn development and data visualization

-Power Query - Data cleaning and transformation

-Dax - Measures and calculations

## Dataset Format

-CSV

## Dataset

The dataset contains employee information,
including:

-Employee details

-Department

-Job function

-Location

-Start date

-Exit date

-Training information

-Performance

-Engagement

-Satisfaction

-Attrition information

## Data Cleaning and Transformation

Power query was used to clean and transform the data.

The cleaning activities included:

-Handling missing values

-Correcting data types

-Standardizing text values

-Checking duplicate records

-Correcting date formats

## Dashboard Pages

The Power BI report contains multiple pages to analyze different areas of HR.

### 1.Workforce Overview

This page provides a view of organization's workforce.

Key areas included:

-Total Employees

-Active Employees

-Employees Left

-Average Age

-Workforce distribution

-Department Analysis

-Location Analysis

-Employee Demographics

![Workforce Overview](Screenshots/workforce-overview.png)

### 2.Employee Performance

This page focuses on employee performance and engagement.

The analysis includes:

-Performance by department

-Engagement versus Performance 

-Employee jobfunction by department

-training outcome analysis

![Employee Performance](Screenshots/employee-performance.png)

### 3.Attrition Analysis

This page focuses on employee attrition.

The analysis includes:

-Total employees who left

-Attrition rate analysis

-Attrition by department

-Attrition by location

-Average age of leavers

-Average satisfaction of leavers

-Voluntary and involuntary termination analysis
